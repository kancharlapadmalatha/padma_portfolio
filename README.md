# 🌐 Personal Portfolio Website

A modern, responsive, and dynamic personal portfolio website built using **HTML, CSS, and JavaScript**. This portfolio showcases my skills, education, projects, and contact information with a clean and professional user interface.

## 🚀 Features

- Responsive design for all devices
- Modern and attractive UI
- Animated typing effect
- Smooth scrolling navigation
- Skills section with progress bars
- Education timeline
- Projects showcase
- Contact section with social media links
- Interactive hover effects and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
